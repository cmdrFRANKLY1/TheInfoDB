# head

The `head` command is a standard command-line utility in Unix, Linux, and other Unix-like operating systems. As its name suggests, it is used to output the first part—the "head"—of files or piped data to the standard output.

# What head Is

When you need to quickly inspect the contents of a massive log file or dataset, opening the entire file in a text editor or printing it with `cat` is inefficient and can overwhelm your terminal. 

The `head` command solves this by grabbing only the very beginning of the file and instantly printing it to your screen. By default, if you run `head` without any specific options, it will print exactly the first 10 lines of the target file. It is the direct counterpart to the `tail` command, which prints the end of a file.

# Common Options

While the default 10-line output is useful, `head` includes several flags that give you precise control over exactly how much data is returned.

## `-n` (Number of Lines)

The `-n` flag allows you to specify exactly how many lines you want to extract from the top of the file. You can pass a number directly after the flag.

## `-c` (Bytes)

If you need even more granular control, the `-c` flag allows you to extract a specific number of raw bytes from the beginning of the file, rather than counting by lines.

## `-q` (Quiet)

When you run `head` on multiple files at the same time, it automatically prints a small header with the file's name before displaying its contents so you know which text belongs to which file. The `-q` (quiet) flag suppresses these file name headers.

## `-v` (Verbose)

The `-v` (verbose) flag forces `head` to always print the file name headers, even if you are only running the command on a single file.

# Practical Examples

Here are the most common ways you will use `head` in the terminal to inspect data.

## Viewing the Beginning of a File

This is the most basic usage, returning the default 10 lines.

* **Command:** `head syslog.log`
* **Result:** Prints the first 10 lines of `syslog.log` to the terminal screen.

## Viewing a Specific Number of Lines

You can easily adjust the output length using the `-n` flag.

* **Command:** `head -n 25 index.html`
* **Result:** Prints the first 25 lines of the `index.html` file.

## Viewing a Specific Number of Bytes

This is particularly useful when inspecting binary files or files without standard line breaks.

* **Command:** `head -c 100 data.bin`
* **Result:** Prints exactly the first 100 bytes of `data.bin`.

## Viewing Multiple Files

You can pass multiple files as arguments. `head` will print the top of each one, separated by a header.

* **Command:** `head script1.js script2.js`
* **Result:** Prints a header `==> script1.js <==` followed by its first 10 lines, then a header for `script2.js` followed by its first 10 lines.

## Piping Output into head

This is one of the most powerful ways to use `head`. You can pipe the output of a very long command into `head` to only see the top results.

* **Command:** `ls -la /etc | head -n 15`
* **Result:** Takes the massive directory listing generated by `ls`, feeds it into `head`, and only prints the first 15 items to your screen.

# Summary

The `head` command is a vital, lightweight text-processing tool. Whether you are checking the column headers of a massive CSV file, verifying the shebang at the top of a script, or limiting the output of a piped command, `head` provides a fast and highly efficient way to peek at your data.
