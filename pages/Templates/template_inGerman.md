# Häufige Befehle

Wenn das Thema Befehle umfasst, liste sie in einer Tabelle mit dem Befehl links und seinem Zweck rechts auf.

## Grundlegende Befehle

| Befehl | Zweck |
| :--- | :--- |
| `befehl-a` | Macht Sache A |
| `befehl-b` | Macht Sache B |
| `befehl-c` | Macht Sache C |

## Fortgeschrittene Befehle

| Befehl | Zweck |
| :--- | :--- |
| `befehl-d --flag` | Macht Sache D mit einem Flag |
| `befehl-e --option=wert` | Macht Sache E mit einer Option |

# Beispiele

Praxisnahe, direkt nutzbare Beispiele für die häufigsten Aufgaben.

## Szenario eins

| Szenario | Befehl |
| :--- | :--- |
| Typischer Anwendungsfall | `befehl-a eingabe.txt` |
| Alternativer Anwendungsfall | `befehl-b --flag eingabe.txt` |
| Stapelverarbeitung | `befehl-a *.txt` |

## Szenario zwei

| Szenario | Befehl |
| :--- | :--- |
| Erstes Beispiel | `befehl-c --mode=fast` |
| Zweites Beispiel | `befehl-c --mode=safe` |
| Drittes Beispiel | `befehl-c --dry-run` |

## Kombinierte Arbeitsabläufe

| Szenario | Befehl |
| :--- | :--- |
| Erst A, dann B | `befehl-a && befehl-b` |
| A ausführen, Ausgabe speichern | `befehl-a > ausgabe.txt` |
| A ausführen, an B weiterleiten | `befehl-a \| befehl-b` |
